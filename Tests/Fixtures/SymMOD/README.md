# Modules de test originaux

Dix modules synthétiques déterministes, générés par `scripts/generate-symmod-corpus.py` avec des oscillateurs créés mathématiquement. Aucune musique ni aucun sample fourni par l’utilisateur ou téléchargé n’est redistribué.

Les noms de fichiers indiquent la caractéristique testée. Les versions PACK emploient des blocs littéraux ; les commandes RLE supplémentaires ont leurs propres fixtures unitaires. Voir `docs/COMPATIBILITE_011.md` pour le périmètre, les limites et la validation Amiga encore nécessaire.
